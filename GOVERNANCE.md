# Governance

Waleed Islam (`@ByWaleed`) is the current project maintainer and release owner.

Routine changes use pull requests and automated checks. Security, authentication, destructive operations, release workflows, and capability gates require maintainer review. Substantial API, compatibility, or governance changes should start with a GitHub issue or discussion.

Sustained contributors can be invited as maintainers after demonstrating sound technical judgment and responsible handling of security-sensitive code.
