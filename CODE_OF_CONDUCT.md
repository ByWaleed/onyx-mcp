# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Contributors must communicate respectfully, accept constructive feedback, and avoid harassment, discrimination, or disclosure of private information.

Report conduct concerns privately to the maintainer through the contact method listed in the GitHub profile for `@ByWaleed`. Maintainers may remove contributions or participants whose behavior is harmful.
